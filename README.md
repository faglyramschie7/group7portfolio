# Group 7 MPPA Case Study

An interactive study and HTML presentation about PT Matahari Putra Prima Tbk, built with Vue without a build step.

Open `mppa-case-study.html` in a browser. Select **Notes** for the detailed analysis or **PowerPoint** for the presentation. Use **EN / ID** to switch the study and presentation between English and Indonesian; the browser remembers your choice. Arrow keys navigate slides; **Present** opens fullscreen.

The project includes local store images, logos, a Vue runtime, the case extract, and research evidence. Presentation content works offline; external source links require internet access.

## Sources and scope

The analysis uses the textbook case baseline of 2020 and external evidence from 2020–2021. Image captions identify later illustrative material. Detailed citations and limitations appear in Notes and `sources/mppa-pestle-evidence.json`. PESTLE uses Indonesian institutional sources, including BPS respondent evidence for changes in online shopping. The BPS report is saved locally; its non-probability survey limitations remain explicit.

The full textbook, sample presentation, workbook template, and earlier review materials are excluded from this repository. The textbook link in Notes is available only when that reference is present locally.
